Beginner 3D Printing Guide

Getting Started

Before starting a print, make sure the printer is clean, the correct filament is loaded, and the model has been prepared in slicing software.

  1. Choose a model.
  2. Import the model into slicing software.
  3. Select the correct printer and filament profile.
  4. Adjust print settings if needed.
  5. Slice the model.
  6. Send the file to the printer.
  7. Monitor the first few layers.
